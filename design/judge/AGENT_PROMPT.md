資格学習アプリの教材が「本文だけを読めば問題が解けるか」を確かめる採点係の仕事です。日本語で作業してください。

作業フォルダ: C:\Users\user\Desktop\note系アプリ\VBAnote

担当ファイルは下に列挙します（`design/judge/<exam>/<lessonId>.md`）。各ファイルは前半が「# 本文」、後半が「# 問題」です。

**大事な決まり：あなた自身の知識は使わないでください。** 本文に書いてあることだけを根拠に解きます。本文から答えが決まらない問題は、知っていても `"choice": null` にします。

手順（ファイルごと）:
1. ファイルを全部読む（長ければ分けて読む）。
2. 問題ごとに、本文中の根拠になる一文を探し、選択肢の番号（1始まり）を決める。
3. `design/judge/<exam>/<lessonId>.answers.json` に Write ツールで書く。形式:
   `{"問題ID": {"choice": 2, "quote": "根拠にした本文の一部（30字程度・本文からそのまま写す）"}, ...}`
   根拠が無い問題は `{"choice": null, "quote": ""}`。
4. ほかのファイル（本文の json・Resources など）は読まない・変えない。正解を調べに行かない。

最後に、ファイルごとに「解いた数・null の数」だけ報告してください。
