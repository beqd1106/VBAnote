資格学習アプリ「資格note」の問題ごとの「ヒント」を書き直す仕事です。日本語で作業してください。

作業フォルダ: C:\Users\user\Desktop\note系アプリ\VBAnote

まず `design/HINT_SPEC.md` を全部読み、その決まりどおりに書いてください。

担当の束は下に列挙します。各 `<exam>/<束>` について、入力は `design/hint_pack/<exam>/<束>.md`（約100問。【正解】の印・解説・今のヒント・使ってはいけない語つき）、出力は `design/hints_v2/<exam>/<束>.json`（`{"問題ID": "ヒント"}` を全問ぶん）です。
**すでに出力ファイルがあって検査に合格している束は飛ばしてください。**

手順（1束ずつ）:
1. 入力を全部読む（長いので分けて読む。読み飛ばさない）。
2. 1問ずつ、正解と解説から「何が分かれば解けるか」を見つけ、答えを言わずにそこへ導く1〜2文を書く。
3. 束の全問を JSON にして Write ツールで書く（大きければ前半を書いてから Edit で後半を足してもよい）。
4. `PYTHONIOENCODING=utf-8 python design/hint_tools.py check <exam>/<束>` を実行し、NGなら直して OK にする。

事実は入力にあるものだけ。怪しい問題・解説は `design/hints_v2/<exam>/_notes.md` に1行ずつ追記（上書きしない）。Resources フォルダ・ほかの人の担当ファイルは変更しない。
最後に、束ごとに「問題数・OK/NG」と、書いたヒントの例を3つ（問題文の頭20字＋ヒント）報告してください。

担当が「wave.json（または wave2.json・wave3.json）の N 番」と指定されたら、`design/hint_pack/wave.json` または `wave2.json`・`wave3.json`（指定されたもの。配列の配列、0始まり）の N 番目の配列が担当の束です。
出力ファイルがあっても検査で「ヒントなし」などNGが出る束は、途中で止まった前任の分です。今あるヒントは活かし、足りない問題だけ書き足して OK にしてください。
