×2: 在庫を多めに持ち棚卸しも減らすのは、重要なAグループには不適切です。

3. ◎高くなる
4. 判断できない
解説: 固定費が増えると、それを回収するのに必要な売上高も増えるため、損益分岐点売上高は高くなります。式で見ると分母の限界利益率が変わらず、分子の固定費だけが大きくなる形です。固定費の増加は利益を出すまでのハードルを上げます。
×1: 固定費が減る場合なら分岐点は低くなりますが、今回は増えているので逆方向です。
×2: 固定費の増減は分子に直接効くので、分岐点は変化します。変わらないのは変動費率や単価のほうです。
×4: 単価・変動費率・固定費の三つが分かっていれば分岐点の方向は式から判断できます。

## b-sc3-12
問題: 著作権法による保護の対象とならないものはどれか。
1. プログラムのソースコード
2. ゲームの画面に使うイラスト
3. ◎プログラムの解法（アルゴリズム）
4. Webサイトに掲載した文章
解説: 著作権は、思想や感情を表現したものを保護し、アイデアそのものは保護しません。プログラムでは、記述したソースコードは保護されますが、その背後にある解法（アルゴリズム）やプログラム言語、規約は対象外です。アイデアを守りたい場合は特許権などを検討します。
×1: ソースコードはプログラムの表現であり、著作物として著作権で保護されます。
×2: イラストは創作的な表現であり、著作物として著作権で保護されます。
×4: 創作的に書かれた文章は言語の著作物であり、著作権で保護されます。

## b-sc3-13
問題: 従業員が職務としてプログラムを作成した場合、特に取り決めがなければ著作者は誰か。
1. ◎従業員を雇用する法人
2. 作成した従業員本人
3. プログラムの利用者
4. 直属の上司個人
解説: 法人などの発意に基づき、従業員が職務として作成した著作物は、特に契約や勤務規則で別の定めがなければ、法人が著作者になります（職務著作）。創作した人が著作者になるという原則の例外です。なお、外部へ委託して作らせた場合は、別途契約で取り決めるのが一般的です。
×2: 作成者本人が著作者になるのが原則ですが、職務著作では例外として法人が著作者になります。
×3: プログラムを使う側は著作者ではなく、利用許諾を受ける立場です。
×4: 上司個人は、指示をしただけでは著作者にはなりません。

## b-sc3-14
問題: 賃金や労働時間など、労働条件の最低基準を定めた法律はどれか。
1. 労働者派遣法
2. 不正競争防止法
3. 個人情報保護法
4. ◎労働基準法
解説: 正解は労働基準法です。賃金・労働時間・休日など、労働条件の最低基準を定めて労働者を守る法律で、正社員か派遣かを問わず適用されます。労働者派遣法は派遣という契約形態のルールを定める法律で、労働条件全般の最低基準を定める法律ではありません。
×1: 労働者派遣法は、派遣事業の運営や派遣労働者の保護について定めた法律です。
×2: 不正競争防止法は、営業秘密の保護など事業者間の公正な競争を守る法律です。
×3: 個人情報保護法は、個人情報の適正な取り扱いを定めた法律です。

## b-sc3-15
問題: 個人情報を取り扱う事業者が守るルールとして、正しいものはどれか。
1. 取得した情報は本人に伝えず別の目的にも使える
2. ◎利用目的をできる限り特定し、本人に通知か公表をする
3. 本人の同意がなくても、第三者へいつでも提供できる
4. 取得から一定期間たったら必ず本人へ返却する
解説: 個人情報を扱う事業者は、利用目的をできる限り特定し、取得時に本人へ通知または公表する必要があります。特定した目的の範囲を超えた利用は、原則として本人の同意が必要です。第三者への提供も、法令に基づく場合などを除き、原則として本人の同意が求められます。
×1: 利用目的を超えた使い方は、原則として本人の同意が必要で、自由にはできません。
×3: 第三者への提供は、例外を除き原則として本人の同意が必要です。
×4: 一定期間で返却する義務はなく、利用する必要がなくなれば遅滞なく消去するよう努めます。

## qc-sc3-01
問題: ある企業が顧客名簿を、アクセス制限も秘密表示もせず全社員が自由に見られる状態で保管していた。退職者が競合に持ち出した場合、不正競争防止法の営業秘密として保護されにくくなる主な理由はどれか。
1. 顧客名簿は事業活動に役立つ情報とは認められないため
2. 特許庁へ出願して登録する手続きを行っていなかったため
3. ◎秘密として管理されていたとはいえないため
4. 退職者は従業員ではなくなっていたため
解説: 営業秘密として保護を受けるには、秘密として管理されていること、事業活動に有用であること、公然と知られていないことが必要です。この例では、アクセス制限や秘密表示がなく、秘密管理の要件を欠くと判断されやすくなります。営業秘密は産業財産権と違い、出願や登録は不要です。
×1: 顧客名簿は一般に事業に有用な情報であり、有用性は問題になりにくい要件です。
×2: 営業秘密は出願や登録が不要で、特許庁での手続きは保護の条件ではありません。
×4: 退職者であっても、不正な目的で営業秘密を使えば規制の対象となるため理由になりません。

## b-sb1-01
問題: 3C分析で分析する3つの要素の組合せはどれか。
1. 市場・技術・価格
2. 製品・価格・販促
3. ◎顧客・競合・自社
4. 強み・弱み・機会
解説: 正解は顧客・競合・自社です。3C分析は、市場や顧客のニーズ、競合他社の動き、自社の強みと弱みを並べて把握し、成功の要因を探すためのフレームワークです。製品・価格・販促を含むのはマーケティングミックスで、強み・弱み・機会はSWOT分析の要素です。
×1: 市場・技術・価格は3C分析の要素ではなく、特定のフレームワークの構成要素でもありません。
×2: 製品・価格・販促（流通を加えて4P）はマーケティングミックスの考え方で、3C分析ではありません。
×4: 強み・弱み・機会は、脅威と合わせて4要素で内外の環境を整理するSWOT分析の要素です。

## b-sb1-02
問題: SWOT分析で、自社の内部環境に当たる要素の組合せはどれか。
1. ◎強み・弱み
2. 機会・脅威
3. 強み・機会
4. 弱み・脅威
解説: 正解は強みと弱みです。SWOT分析では、自社の努力で変えられる内部環境を強み・弱みとして、自社ではコントロールしにくい市場や法規制などの外部環境を機会・脅威として整理します。機会・脅威は外部環境なので、内部と外部を取り違えないことが大切です。
×2: 機会・脅威は、市場動向や競合、法改正など自社の外にある外部環境の要素です。
×3: 強みは内部環境ですが、機会は外部環境なので、内部だけの組合せにはなりません。
×4: 弱みは内部環境ですが、脅威は外部環境なので、内部だけの組合せにはなりません。

## b-sb1-03
問題: PPMで、市場成長率も市場占有率も高い事業の呼び名はどれか。
1. 金のなる木
2. ◎花形
3. 問題児
4. 負け犬
解説: 正解は花形です。成長市場で高い占有率を持つ主力の事業で、売上は大きい一方、成長を維持するために多額の投資も必要になります。同じく占有率が高い金のなる木は成長率が低く、投資が少なくて済むため、資金の稼ぎ手になる点が違います。
×1: 金のなる木は占有率が高いものの市場成長率が低い事業で、投資が少なく資金を生み出します。
×3: 問題児は市場成長率が高いものの占有率が低い事業で、育てるか見切るかの判断が必要です。
×4: 負け犬は市場成長率も占有率も低い事業で、撤退も検討される対象です。

## b-sb1-04
問題: PPMで、市場成長率は高いが市場占有率が低い事業の呼び名はどれか。
1. 花形
2. 金のなる木
3. 負け犬
4. ◎問題児
解説: 正解は問題児です。成長市場にいるものの占有率が低く、シェアを取るには投資が必要で、将来は花形にも負け犬にもなり得る事業です。育てるか撤退するかの判断が求められる点が特徴で、占有率が高い花形とは、占有率の高低で区別します。
×1: 花形は市場成長率も占有率も高い事業で、主力として売上を支える存在です。
×2: 金のなる木は占有率が高く成長率が低い事業で、安定した資金源になります。
×3: 負け犬は成長率も占有率も低い事業で、将来の見込みが薄く撤退も検討されます。

## b-sb1-05
問題: PPMで、成長率も占有率も低く、撤退も検討される事業の呼び名はどれか。
1. ◎負け犬
2. 花形
3. 金のなる木
4. 問題児
解説: 正解は負け犬です。市場の成長が見込めず占有率も低いため、投資しても大きな収益が期待しにくく、撤退や縮小を検討する対象になります。成長率は高いが占有率が低い問題児とは、市場自体に伸びしろがあるかどうかで区別します。
×2: 花形は成長率も占有率も高い事業で、撤退ではなく維持・強化の対象になります。
×3: 金のなる木は占有率が高い事業で、撤退ではなく資金源として活用されます。
×4: 問題児は市場が成長している事業で、育成か撤退かを判断しますが、市場自体は伸びています。

## b-sb1-06
問題: M&Aの説明として正しいものはどれか。
1. 自社の製品を他社の店舗で販売する契約
2. 技術や設計を他社に使わせて対価を得る
3. ◎他の企業を合併したり買収したりすること
4. 自社の業務を外部の専門企業に委託すること
解説: 正解は、他の企業を合併したり買収したりすることです。M&Aは、事業の拡大や新分野への進出、不足する技術や人材の獲得を短期間で実現するために使われます。業務の外部委託はアウトソーシング、技術の使用許諾はライセンス契約という別の手法です。
×1: 他社の店舗で自社製品を販売する契約は、販売面での業務提携にあたり、経営権の取得を伴うM&Aではありません。
×2: 技術や設計を使わせて対価を得る仕組みはライセンス契約で、企業そのものを取得するM&Aとは異なります。
×4: 業務を外部の専門企業に任せることはアウトソーシングで、企業の合併や買収ではありません。

## b-sb1-07

## b-sb1-08
問題: アンゾフの成長マトリクスで、既存の市場に既存の製品で売上拡大を図る戦略はどれか。
1. 新製品開発
2. 新市場開拓
3. 多角化
4. ◎市場浸透
解説: 正解は市場浸透です。今の市場と今の製品はそのままに、販促の強化や価格の見直しなどでシェアを高め、売上を伸ばす戦略で、4つの中で最も新しさが少なくリスクも小さい選択肢です。製品か市場のどちらかを新しくする場合は、新製品開発や新市場開拓になります。
×1: 新製品開発は、既存の市場に向けて新しい製品を投入して成長を図る戦略です。
×2: 新市場開拓は、既存の製品を新しい市場や顧客層へ展開して成長を図る戦略です。
×3: 多角化は、新しい市場に新しい製品で進出する戦略で、4つの中で最も変化が大きくなります。

## b-sb1-09

×2: 市場浸透は、既存の市場に既存の製品で売上を伸ばす戦略で、新しい要素を含みません。
×3: 新製品開発は、既存の市場に新しい製品を出す戦略で、市場は変わりません。
×4: 新市場開拓は、既存の製品を新しい市場に展開する戦略で、製品は変わりません。

## b-sb1-10

×4: M&Aもアライアンスも国内外を問わず行われ、両者の違いは国内か国際かではなく、経営権の取得の有無です。

## qc-sb1-01
問題: 国内で好調な食品メーカーが、主力商品を改良せずにそのまま海外の消費者向けに販売し始めた。この戦略はアンゾフの成長マトリクスでどれに当たるか。
1. ◎新市場開拓
2. 市場浸透
3. 新製品開発
4. 多角化
解説: 正解は新市場開拓です。製品は既存のままで、販売先を国内から海外という新しい市場に広げているため、既存製品×新規市場に当たります。製品を作り替えて同じ市場に出すなら新製品開発、新しい製品を新しい市場に出すなら多角化になる点で区別します。
×2: 市場浸透は既存市場で既存製品の売上を伸ばす戦略で、海外という新しい市場には広げていません。
×3: 新製品開発は既存市場に新しい製品を投入する戦略で、製品を改良していないため当てはまりません。
×4: 多角化は新市場に新製品で進出する戦略で、今回は製品が既存のままなので当てはまりません。

## qc-sb1-02
問題: 法改正により、自社が得意とするサービスの需要が拡大する見込みである。この事実はSWOT分析でどこに整理するのが適切か。
1. 強み
2. 弱み
3. 脅威
4. ◎機会
解説: 正解は機会です。法改正は自社の外で起きる変化で、自社の努力では左右できない外部環境にあたり、しかも自社に追い風となるため機会に整理します。得意なサービスを持っていること自体は強みですが、今回の事実は需要の拡大という外部の変化を指しています。
×1: 強みは自社の内部にある優れた点で、法改正という外部の出来事そのものは強みには分類されません。
×2: 弱みは自社の内部にある不足点で、需要拡大という追い風を表す今回の事実とは合いません。
×3: 脅威は自社に不利に働く外部の変化で、需要が拡大する今回の事実は有利な変化なので当てはまりません。

## b-sb2-01
問題: 4Pのうち、品質・機能・デザインなど商品そのものの内容を決める要素はどれか。
1. Price（価格）
2. Place（流通）
3. ◎Product（製品）
4. Promotion（販促）
解説: 正解はProduct（製品）です。何を提供するかを決める要素で、品質・機能・デザイン・ブランド名・パッケージなどが含まれます。Price は売値の決定、Place は届ける経路、Promotion は広告や販売促進で、いずれも商品の中身ではなく売り方側の要素です。
×1: 価格は売値や割引の決め方であり、商品の中身ではありません。
×2: 流通は店舗やネットなど届ける経路の選択で、商品の内容とは別です。
×4: 販促は広告・キャンペーンなどで知ってもらう活動であり、商品自体ではありません。

## b-sb2-02
問題: 4Pのうち、広告・キャンペーン・販売員による説明など、商品の魅力を顧客に伝える活動はどれか。
1. ◎Promotion（販促）
2. Product（商品開発）
3. Price（価格設定）
4. Place（流通経路）
解説: 正解はPromotion（販売促進）です。広告、キャンペーン、クーポン、販売員の接客など、商品を知ってもらい購入につなげる活動をまとめた要素です。Product は商品の中身、Price は価格設定、Place は販売経路を決めるもので、顧客への情報伝達や働きかけそのものではありません。
×2: 製品は商品の品質や機能の設計を指し、顧客への伝達活動ではありません。
×3: 価格は売値や割引条件の設定であり、伝える活動とは別の要素です。
×4: 流通は商品を届ける経路の選択で、魅力を伝える活動ではありません。

## b-sb2-03
問題: 市場を年齢・性別・地域・価値観などの基準で、似た特徴のグループに分けることを何というか。
1. ターゲティング
2. ◎セグメンテーション
3. ポジショニング
4. マーケティングミックス
解説: 正解はセグメンテーション（市場細分化）です。STP の最初の段階で、不特定多数の市場を共通の特徴を持つ顧客グループに分けます。ターゲティングは分けた中から狙う層を選ぶ段階、ポジショニングは競合との違いで立ち位置を決める段階で、順序と役割が異なります。
×1: ターゲティングは分けた後に狙う層を選ぶ段階で、分ける作業ではありません。
×3: ポジショニングは競合に対する自社の立ち位置を決める段階です。
×4: マーケティングミックスは4Pを組み合わせて施策を設計することで、市場を分ける手順ではありません。

## b-sb2-04
問題: STPのうち、細分化した市場の中から、自社が狙う顧客層を選ぶ段階はどれか。
1. セグメンテーション
2. ポジショニング
3. ◎ターゲティング
4. プロモーション
解説: 正解はターゲティングです。セグメンテーションで分けたグループの中から、自社の強みが活きて収益が見込める層を選びます。セグメンテーションは分ける段階、ポジショニングは選んだ層の中での自社の立ち位置の決定です。プロモーションは4Pの要素でSTPの段階ではありません。
×1: セグメンテーションは市場を分ける段階で、狙う層を選ぶ段階ではありません。
×2: ポジショニングは競合との違いを明確にする段階で、層を選ぶ作業ではありません。
×4: プロモーションは4Pの販売促進を指す語で、STPの段階ではありません。

## b-sb2-05
問題: STPのうち、競合製品との違いを際立たせ、顧客の心の中での自社製品の位置づけを決める段階はどれか。
1. セグメンテーション
2. ターゲティング
3. リーチ
4. ◎ポジショニング
解説: 正解はポジショニングです。「低価格」「高品質」「健康志向」など、競合と比べた自社製品の独自の立ち位置を、ターゲットの顧客に明確に伝わる形で決めます。セグメンテーションは市場を分ける段階、ターゲティングは狙う層を選ぶ段階で、競合との差別化を決める段階ではありません。
×1: セグメンテーションは市場を分ける段階で、競合との差別化とは別です。
×2: ターゲティングは狙う顧客層を選ぶ段階で、立ち位置を決める段階ではありません。
×3: リーチは広告が届いた人数などを指す語で、STPの段階ではありません。

## b-sb2-06
問題: 顧客の情報を一元管理し、長期的な良好な関係を築いて売上や満足度を高める考え方・仕組みはどれか。
1. ◎CRM
2. SCM
3. ERP
4. SFA
解説: 正解はCRM（顧客関係管理）です。購入履歴や問い合わせ内容などを蓄積して顧客ごとに最適な対応を行い、継続的な取引につなげます。SCM は原材料から販売までの供給の流れの管理、ERP は会社全体の経営資源の統合管理、SFA は営業活動の支援で、顧客との関係強化が中心ではありません。
×2: SCMは調達・生産・物流など供給の流れ全体を管理する手法です。
×3: ERPは人・物・金などの経営資源を統合して管理する仕組みです。
×4: SFAは営業担当者の活動や商談を管理・支援する仕組みです。

## b-sb2-07
問題: ブランド戦略の目的として、最も適切なものはどれか。
1. 仕入れ先を増やして調達にかかるコストを下げること
2. ◎他社製品と区別され、顧客に愛着を持ってもらうこと
3. 従業員の勤務時間を短くして残業を大幅に減らすこと
4. 製品を一度に大量に生産して在庫を多く持つこと
解説: ブランド戦略は、名称・ロゴ・品質イメージなどを通じて他社製品と識別され、顧客に信頼や愛着を持ってもらうための取り組みです。価格競争に頼らず選ばれる理由をつくる点が狙いです。調達コストの削減、労働時間の短縮、大量生産は、いずれもブランド価値の向上を目的とした施策ではありません。
×1: 仕入れ先の拡大は調達の取り組みであり、顧客の信頼や愛着とは関係がありません。
×3: 勤務時間の短縮は働き方の改善で、ブランドの価値づくりとは別です。
×4: 大量生産と在庫の確保は生産・在庫管理の話で、ブランドとは別です。

## b-sb2-08
問題: 購入履歴などをもとに、その顧客に合いそうな商品を自動的に提示する仕組みを何というか。
1. ロングテール
2. オムニチャネル
3. ◎レコメンデーション
4. ダイレクトマーケティング
解説: 正解はレコメンデーションです。ネット通販や動画配信で、過去の購入・閲覧履歴や他の顧客の傾向から、関心を持ちそうな商品を自動で表示します。ロングテールは売れ筋でない商品群の累積売上の考え方、オムニチャネルは販売経路の連携、ダイレクトマーケティングは顧客へ直接働きかける手法で、いずれも商品を提示する仕組みではありません。
×1: ロングテールは少量しか売れない多品種の累積売上が大きくなる考え方です。
×2: オムニチャネルは店舗やネットなど複数の接点を連携させる戦略です。
×4: ダイレクトマーケティングは顧客へ直接案内や販売を行う手法で、商品の自動提示ではありません。

## b-sb2-09
問題: 実店舗とネット通販など複数の販売経路を連携させ、顧客がどの経路でも同じように買えるようにする戦略はどれか。
1. ロングテール戦略
2. ダイレクトマーケティング
3. ブランドエクステンション
4. ◎オムニチャネル
解説: 正解はオムニチャネルです。店舗・ネット・アプリなどあらゆる顧客接点を連携させ、在庫や会員情報を共通化して、どの経路でも一貫した購買体験を提供します。ロングテールは品ぞろえの考え方、ダイレクトマーケティングは顧客へ直接働きかける手法、ブランドエクステンションは既存ブランドを新商品に広げる戦略です。
×1: ロングテールは経路の連携ではなく、売れ筋以外の商品群の累積売上に注目する考え方です。
×2: ダイレクトマーケティングは顧客へ直接販売や案内を行う手法で、経路の連携とは異なります。
×3: ブランドエクステンションは既存ブランドの知名度を新商品へ広げる戦略です。

## b-sb2-10
問題: 基本的な機能は無料で提供し、より高度な機能を使いたい利用者から料金を得るビジネスモデルはどれか。
1. ◎フリーミアム
2. サブスクリプション
3. アフィリエイト
4. クラウドファンディング
解説: 正解はフリーミアムです。無料利用者を多く集めて認知度を高め、その一部が高機能版などの有料プランに移行することで収益を得ます。サブスクリプションは定額で継続利用させる課金方式、アフィリエイトは成果報酬型の広告、クラウドファンディングは多数の人から資金を募る仕組みで、無料と有料を併用する形ではありません。
×2: サブスクリプションは月額などで継続利用させる課金方式で、無料利用が前提ではありません。
×3: アフィリエイトは他サイトの広告経由の成果に応じて報酬を払う仕組みです。
×4: クラウドファンディングはプロジェクトの資金を不特定多数から募る方法です。

## b-sb2-11
問題: 顧客が取引期間全体を通じて自社にもたらす利益の総額を表す指標はどれか。
1. CS（顧客満足度）
2. ◎LTV（顧客生涯価値）
3. 市場占有率（マーケットシェア）
4. 客単価（1回の購入額）
解説: 正解はLTV（顧客生涯価値）です。1人の顧客が取引を始めてから終えるまでに自社にもたらす利益の合計で、新規獲得よりも継続して購入してもらう施策の重要性を示します。顧客満足度は満足の度合い、市場占有率は市場全体に占める自社の販売割合、客単価は1回当たりの購入額で、期間全体の利益ではありません。
×1: 顧客満足度は利益ではなく、サービスへの満足の度合いを表す指標です。
×3: 市場占有率は市場全体の売上のうち自社が占める割合です。
×4: 客単価は顧客1人の1回あたりの購入金額で、取引全期間の合計ではありません。

## qc-sb2-04
問題: RFM分析の結果、最優先で特典を送るべき顧客として最も適切なものはどれか。

4. 購入回数が多いが、最終購入が1年以上前の顧客

×2: 最終購入が古い（Rが低い）ため、現在の関係が弱く優先度は下がります。
×3: 購入が一度だけ（Fが低い）で、継続的な顧客とは判断できません。
×4: 最終購入が古く（Rが低く）、離脱している可能性が高い顧客です。

## b-ss3-03

## qc-md1-03
問題: モジュール分割で、モジュールどうしの独立性を高める方針として、適切なものはどれか。
1. 一つのモジュールにできるだけ多くの機能を詰め込む
2. モジュール間で互いの内部処理を直接呼び出せるようにする

×2: 内部処理を直接呼び出すと、互いの変更の影響を受けやすくなり、独立性が下がります。
×4: 共通の変数を共有すると、一か所の変更が全体に波及し、結びつきが強くなります。
