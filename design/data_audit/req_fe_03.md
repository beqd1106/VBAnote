## d-al1-06

○整数型: i, s
s ← 0

  s ← s + a[i]

×3: 終わりの値が 要素数(a) なら最後の要素 a[3] まで届きます。

## d-al1-08
問題: 「x > 0 and y > 0」ではない（否定になる）ことを表す式はどれか。
1. x ≦ 0 and y ≦ 0
2. x < 0 or y < 0
3. ◎x ≦ 0 or y ≦ 0
4. x < 0 and y < 0

×4: and のままで 0 も抜けており、否定の範囲を狭く捉えすぎています。

## d-al1-09
問題: 次のプログラムを実行した後の a はどれか。
○整数型の配列: a ← {0, 0, 0, 0}
○整数型: i
for (i を 1 から 4 まで 1 ずつ増やす)
  a[i mod 3 + 1] ← a[i mod 3 + 1] + i

2. ◎{3, 5, 2, 0}
3. {3, 2, 5, 0}
4. {1, 2, 3, 4}

×4: 各 i を a[i] に足したときの結果で、添字は i mod 3 + 1 で決まります。

## d-al1-10
問題: do … while と while の違いの説明として正しいものはどれか。
1. ◎do … while では、条件が最初から偽でも本体が1回は実行される
2. while では、本体を実行した後に条件を調べる
3. do … while は、条件が偽の間だけ繰り返す
4. while では、条件が偽でも本体が1回は実行される
解説: do … while は本体を実行してから条件を調べるので、最初から偽でも1回は実行されます。while は先に条件を調べ、偽なら一度も実行しません。どちらも条件が真の間だけ繰り返す点は同じで、違いは条件を調べる順序だけです。
×2: 条件を後で調べるのは do … while で、while は本体の前に調べます。
×3: どちらも条件が真の間だけ繰り返し、偽になると繰返しを抜けます。
×4: 条件が最初から偽でも1回実行されるのは do … while で、while は実行しません。
