解説: 退職者が出た場合は、そのIAMユーザーのアクセス権限やアクセスキーを速やかに無効化・削除し、不要なアクセスを残さないことが基本です。ルートユーザーの認証情報を共有したり、MFAを全員解除したりする対応とは正反対に、対象者のアクセスだけを個別に止める点が区別のポイントです。
×1: ルート共有は厳禁です。
×2: MFA解除は安全性を下げます。
×3: パスワード公開は重大なリスクです。

## q9-sec-05
問題: 「OSのセキュリティパッチ適用」が利用者の責任になるのは、次のうちどのサービスですか。
1. ◎Amazon EC2
2. Amazon S3
3. Amazon DynamoDB
4. AWS Lambda
解説: EC2はIaaSで、ゲストOSのパッチ適用は利用者の責任です。Lambda・S3・DynamoDBはマネージドで、基盤OSはAWSが管理します。
×2: S3は基盤をAWSが管理します。
×3: DynamoDBもAWSが基盤を管理します。
×4: Lambdaの実行環境はAWSが管理します。

## q9-sec-06
問題: オンプレミスとAWSを安価・手軽に暗号化接続したい。最も適切なのはどれですか。
1. Amazon S3
2. ◎AWS Site-to-Site VPN
3. AWS Direct Connect（専用線）
4. Amazon CloudFront
解説: VPNはインターネット経由で暗号化トンネルを張る手軽な接続です。専用線で安定性・帯域を重視するならDirect Connectを使います。
×1: S3はストレージです。
×3: Direct Connectは専用線で導入の手間とコストが大きめです。

## q9-sec-07
問題: 「リソースが社内ルール（例：暗号化必須）に準拠しているか継続評価」したい。最適なのはどれですか。
1. Amazon CloudFront
2. AWS Budgets
3. ◎AWS Config
4. AWS CloudTrail
解説: 正解はAWS Configです。Configは、AWSリソースの構成情報を継続的に記録・評価し、暗号化の有効化など社内で定めたルールに準拠しているかを継続的にチェックできるサービスです。コンテンツ配信のCloudFront、予算アラートのBudgets、操作履歴を記録するCloudTrailとは目的が異なり、構成の継続的な評価という点がConfigの核心です。
×1: CloudFrontはCDNです。
×2: Budgetsは予算アラートです。
×4: CloudTrailは操作履歴の記録です。

## q9-sec-08
問題: 【総復習】IAMのベストプラクティスとして適切なものを2つ選んでください。
1. ◎重要操作・ルートにMFAを設定する
2. ◎役割に応じて最小権限を付与する
3. アクセスキーを公開リポジトリに置く
4. 全員に管理者権限を付与する
解説: 正解は「重要操作・ルートにMFAを設定する」と「役割に応じて最小権限を付与する」です。MFAは認証を二重にして不正ログインを防ぎ、最小権限の原則は必要な操作だけを許可して被害範囲を抑えます。逆に、アクセスキーを公開リポジトリに置いたり、全員に管理者権限を与えたりすると、漏えいや誤操作の影響が組織全体に及ぶため避けるべき運用です。
×3: キーの公開は漏えいの典型です。
×4: 全員管理者は被害範囲を広げます。

## q9-tech-03
