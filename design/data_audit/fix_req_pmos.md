## q-po3-08
問題: 会議でPMとシステム部門が対立して議論が進まない。PMOメンバーが発揮すべきスキルはどれか。
1. ◎双方の意見を引き出し合意へ導く技術
2. 対立を避けて議事録だけを整える対応

×3: スケジュールの再作成はPM知識に関わる作業ですが、対立した意見を整理して合意に導く場面の解決策ではありません。
×4: 業務知識は大切ですが、自分で処理して解決する力ではありません。対立する当事者の意見を調整する力が必要です。
指摘(種類4): ×4が選択肢にない業務知識を論じている ／ 直し案: ×4を「自分で業務を処理しても、当事者間の対立の調整にはならない」に差し替える

## q-rk1-02
問題: 三つのリスクがある。Aは確率10%・損失300万円、Bは確率40%・損失100万円、Cは確率50%・損失60万円である。期待金額の合計をコンティンジェンシー予備の目安にするとき、金額はいくらか。

## d-rk1-09
問題: リスクX（確率70%・損失100万円）、Y（確率10%・損失600万円）、Z（確率50%・損失90万円）がある。期待金額が大きい順に並べたものはどれか。
1. Y、X、Z
2. ◎X、Y、Z
3. Y、Z、X
4. X、Z、Y
解説: 期待金額は確率×損失額で、X＝70万円、Y＝60万円、Z＝45万円となり、大きい順はX、Y、Zです。損失額だけで並べるとYが先頭になりますが、確率を掛けて初めてリスクの大きさを比べられます。検算では、各積を先に出してから比べると確実です。
×1: 損失額の大きい順に並べた結果で、確率を掛けずに比べてしまっている。
×3: 確率の低い順に並べた結果で、期待金額の大小とは一致しない並びである。
×4: 確率の高い順の並びで、XとZを入れ替えた期待金額の比較になっていない。
指摘(種類4): ×3の並びは確率の低い順ではない ／ 直し案: 「YはXより期待金額が小さく、ZはXより小さい」に修正

## d-rk2-01
問題: コミュニケーション経路の数を求める式n( )/2の、かっこに入る正しい式はどれか。ただしnは人数とする。
1. n+1
2. n
3. 2n
4. ◎n-1
解説: 人数nの全員が互いに1対1で連絡するときの経路数は、n(n-1)/2です。各人が自分以外のn-1人とつながり、同じ組合せを2回数えないように2で割ります。n+1や2nを使うと、人数が増えたときの経路数を誤って見積もります。
×1: n+1では自分以外の人数にならず、4人のとき10本となり、正しい6本と一致しない。
×2: nのままでは自分自身との連絡も数えることになり、実際の組合せより多くなる。
×3: 2nでは人数に比例するだけで、組合せの増え方を表せず、経路数が過小になる。
指摘(種類4): ×3の2nは人数に比例せず経路数も過小でない ／ 直し案: 「2nではn²となり、同じ組合せを重複して数える」に修正

## b-rk3-05
問題: 実費償還型契約の特徴として、最も適切なものはどれか。
1. 総額を契約時に固定し、コスト超過のリスクを受注者が負う
2. ◎かかった実費に報酬を加えて支払い、超過リスクは発注者が負う
3. 作業時間にかかわらず単価を固定し、費用の精算は一切行わない
4. 成果物が完成した時点で初めて、費用の一部だけが支払われる
解説: 実費償還型は、かかった実費に報酬を上乗せして支払う方式です。費用が増えれば発注者の支払いも増えるので、コスト超過のリスクは発注者側にあります。範囲が定めにくい研究的な仕事などで使われます。一括請負とはリスクの負担者が逆になります。
×1: 総額固定でリスクを受注者が負うのは一括請負で、実費償還型とは逆の考え方です。
×3: 単価固定で時間に応じて精算するのはタイム・アンド・マテリアルで、実費を償還する方式とは異なります。
×4: 完成して初めて支払うのは請負の考え方で、実費償還型は費用の発生に応じて支払います。
指摘(種類4): ×3が選択肢3の「精算しない」と食い違う ／ 直し案: ×3を「作業量に応じた精算を行わないという説明は、実費償還型ではありません」に変更
